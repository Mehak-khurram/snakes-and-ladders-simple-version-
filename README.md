# 🎲 Simple Snakes and Ladders (C++ Console Game)

This project is a simplified console-based version of Snakes and Ladders written in C++.
It features a two-player dice-rolling game where the first player to reach exactly 20 wins a round.
The game continues for a maximum of 5 rounds, and the first player to win 3 rounds is declared the overall winner.

# 🕹️ How the Game Works

Two players take turns rolling a dice (1–6).

Players press Enter to roll.

Their scores increase according to the dice value.

If a move exceeds 20, it is not allowed and the player stays in place.

A player wins a round by landing exactly on 20.

First to win 3 rounds wins the game.

# 🛠️ Features

Simple turn-based gameplay

Randomized dice rolls

Move validation

Round tracking

Win counter for each player
